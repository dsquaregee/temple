# Tirukkannarkoil (Kurumanakkudi) — Kannayiranathar Temple

- **Deity:** Shiva as **Kannayiranathar** (Kannayiram Udayar, 'thousand-eyed lord'); goddess **Murugu Valar Kothai Nayaki** (Kothai Nayaki; Sugandha Kundalambikai). (Worklist goddess "Murugu Valar Kothai Nayaki" — confirmed.)
- **Location:** **Kurumanakkudi**, a.k.a. Tirukkannarkoil / Kannarkovil, ~5 km from **Vaitheeswaran Koil**, 8 km from Sirkazhi, Tarangambadi taluk, **Mayiladuthurai district** (older sources: Nagapattinam). ~11.17 N, 79.73 E (approximate). PIN 609117.
- **Tradition:** Paadal Petra Sthalam — hymned by **Tirugnana Sambandar**; northern Kaveri bank.
- **Festivals:** Maha Shivaratri (Masi); Navaratri (Purattasi); Karthikai Mondays; Pradosham.

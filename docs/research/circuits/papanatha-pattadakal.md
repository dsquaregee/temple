# Papanatha Temple, Pattadakal (papanatha-pattadakal)

- Coordinates used: 15.9479, 75.8172 (UNESCO nomination: N15°56'52.3" E75°49'1.9").
- Dating disputed: c. 680 CE (ANU archive) to 8th c.; some sources 697-733. Shiva temple, last-but-one of the Shaiva group (UNESCO: ninth Shaiva sanctuary).
- Style: mix of Nagara (northern curvilinear tower over main sanctum) and Dravida (miniature Dravida elements on a smaller eastern part); ASI groups it with the Nagara temples. Natya mandapa (dancing hall) mentioned.
- Reliefs of Ramayana and Mahabharata scenes on outer walls.
- Earlier name "Mulasthana Mahadeva" per an 11th-century inscription found nearby (Sarmaya). Set apart toward the village, built beside the village wall (Sarmaya photo title).
- UNESCO 1987.
- Unconfirmed: inscription details, opening hours.

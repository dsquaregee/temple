# Thiruneeragam — Jagadeeshwara Perumal (within the Ulagalantha Perumal temple, Kanchipuram)

Thondai Nadu Divya Desam. Assigned id: `jagadeeshwara-thiruneeragam`. Master list correct.
One of the four Divya Desams housed in the Ulagalantha Perumal temple complex
(with Thiruooragam, Thirukkaragam, Thirukkarvanam).

## Facts
- Presiding deity: Jagadeeshwara Perumal; consort Nilamangaivalli (Nilamangai Valli) Thayar
  (greenmesg.org; indiatempletour blog).
- There is no moolavar image; the utsavar (processional image) is worshipped (greenmesg.org).
- Name: "neer" = water; devotional accounts say the Lord is like water, equal to all beings
  (ranjustemplevisits blog) — used as "devotional reading", not as fact.
- Tank: Akrura Theertham; Vimanam: Jagadeeshwara Vimanam; pratyaksham: Akrura (greenmesg.org).
- Mangalasasanam: Thirumangai Alvar, 1 pasuram (greenmesg.org) — single source.
- The four shrines are believed to have once been independent temples, brought together in the
  Ulagalantha complex for reasons not recorded; one verse of Thirumangai Alvar names them
  (incredibleindia.gov.in).
- Host temple history: Pallava foundation by tradition; Chola, Vijayanagara and Nayak additions;
  Pallava/Chola inscriptions (Wikipedia; incredibleindia). Administered by HR&CE.
- Listed as the 47th Divya Desam in one traditional numbering (greenmesg.org) — not used.
- Coordinates: shrine inside the Ulagalantha Perumal temple, so the host temple's Wikipedia
  coordinates are used: 12.8392, 79.7050.
- Festivals: shares the host temple's calendar; specifics not confirmed.
